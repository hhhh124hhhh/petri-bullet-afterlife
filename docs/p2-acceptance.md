# P2 验收方案：决策是否成立

> P2 是四个原型里最重要的 Gate。只回答一个问题：**三选一摆在面前时，玩家是否会根据战况改变选择？还是永远选同一个？**

## 一、做什么（最小集合）

1. **经验 / 升级**：杀怪得经验，经验满升一级，每级暂停游戏弹一次三选一。
2. **SAMPLE**：怪死亡掉落绿色样本，走近自动拾取；攒够数才能点分支进化。
3. **三选一 UI**：三张卡片，点选其一后游戏继续。
4. **4 技能槽**：开局脉冲针占 1 槽；三选一可以拿新技能（离心刃 / 电弧）或升级已有技能。
5. **两个分支**（脉冲针 Lv3 时不可逆二选一，P2 只验分支决策本身）：
   - A·针雨路线：每次射击变扇形 3 发，清群强，单体弱。
   - B·处决路线：连续命中同一目标叠层，第 5 发 +150%，切目标清零，单体强。

## 二、三选一选项池（每次发牌必须覆盖三类）

| 类别 | 示例 |
|---|---|
| 强化当前构筑 | 已有技能 +1 级（伤害/数量提升） |
| 补弱点 | 生命上限 +30 / 移速 +15%（安全向） |
| 改变路线 | 新技能入槽 / 分支进化（需 SAMPLE 够数） |

设计铁律：一个选项如果没让另一个有价值的东西更难获得，它就不是真选择。每次发牌三类必须齐，逼玩家做取舍。

## 三、验收标准

- 用户打 3 局，每局至少遇到 3 次三选一。
- **通过**：选择记录显示非常选固定项，或用户反馈"有几次纠结了，不知道选啥"。
- **失败**：3 局每次都选同一个（例如永远选伤害）→ 伪构筑，设计打回重做。

## 四、不做的（留给 P3/P4）

正式美术、音效、局外 Meta、Boss 战、8 分钟完整流程、商店系统。

## 五、与 P1 的关系

P1 已验收（战斗爽感 ✅）。P2 不动 P1 的手感与反馈，只加系统层。P1 遗留的"容易死"数值问题放到 P2 一起调——有了防御/生命选项后，生存调参才有意义。
