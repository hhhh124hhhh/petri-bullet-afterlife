# 《培养皿：弹幕余生》竖屏网页重制版设计文档
**《培养皿：弹幕余生》 PETRI: BULLET AFTERLIFE**
类型：竖屏 Survivors-like / 轻 Roguelite
平台：手机浏览器 / itch.io
技术：HTML5 Canvas + JavaScript，纯前端，无后端
目标单局时长：7–9 分钟
操作方式：单指虚拟摇杆，自动攻击
首版内容目标：1 角色、6 基础技能、6 个进化技能、8 种普通敌人、2 精英、1 Boss、1 张地图

> 来源：ChatGPT Plus 网页端设计委托，2026-10-07。对话：https://chatgpt.com/c/6ac60526-efd4-83ea-b847-5ff54e8e163d

下面这版按"先验证核心决策空间，再扩内容"来设计。核心不再围绕"弹药=生命"强行做文章，而是把《培养皿》真正可继承的辨识度收束为：培养皿空间压迫 + 走位采样资源 + 三方向互斥构筑 + 机制 Boss。

## 一、设计支柱
新版只围绕四个设计支柱展开：
**1. 动起来才有资源** —— 经验不是唯一掉落。玩家必须主动进入危险区域拾取：经验数据、观察样本、临时补给、Boss 机制资源。因此"绕场苟活"只能活下来，不能形成最强构筑。
**2. 每次三选一都是路线选择** —— 技能不存在单纯意义上的 A 是 B 的伤害更高版本。升级必须至少在以下两项之间制造冲突：输出、生存、范围、控场、资源获取、机动性。同一技能在中期开始产生不可逆分支。
**3. 强技能必须有结构性代价** —— 任何单个技能禁止同时取得：高 DPS + 高安全性 + 高资源效率。这是新版最高优先级平衡规则。
**4. Boss 考的是理解，不是 DPS** —— Boss 战允许低配构筑通过。玩家失败应更多来自"我没看懂"，而不是"我的数值没刷够"。

## 二、世界观
**2.1 一句话简介** —— 在废弃实验室的培养皿中，用生命值当弹药，杀出一条弹幕余生。这里的"生命值当弹药"保留为主题表达，而不直接绑定基础射击消耗。它代表：PETRI-07 的全部战斗行为，本质上都在消耗一具已经停止维护的实验体。
**2.2 背景故事** —— 实验设施 LAB-07 已经废弃了 17 年。但地下观察舱依旧运行。你是最后一个仍然响应命令的实验机器人：PETRI-07。培养皿里那些橙色生物并非真正的感染者。它们是实验室不断注入的"变量"。观察系统仍按照最后一道指令运行：制造压力。记录反应。寻找极限。每一次弹幕、每一次感染、每一次突变，都只是一次新的实验条件。而培养皿中央那具紫色实验体，则是系统在你之前测试过的失败样本。编号：PETRI-06。它没有逃出去。它学会了如何成为观察协议的一部分。
**2.3 商店页文案**
《培养皿：弹幕余生》

你不是英雄。

你只是一个还没被宣布死亡的实验样本。

在不断封闭的培养皿中移动、采集、变异，利用实验室留下的武器模块构筑自己的战斗方式。

自动攻击，但绝不意味着自动获胜。

靠近高危区域获取稀有样本，在输出、安全与资源之间做选择；观察敌人的行为，寻找弹幕之间短暂的安全区。

7 分钟之后，观察协议将释放它曾经最失败、也最危险的实验结果。

你能证明 PETRI-07 与它不同吗？

特点：单手操作的竖屏生存战斗；每局约 7–9 分钟；多路线技能进化；强技能必有代价；依靠读招而非堆数值的 Boss 战；无广告、无联网要求；手机浏览器即开即玩。

## 三、美术风格指南
**3.1 核心视觉定位** —— 霓虹实验室 × 街机像素 × 生物污染。关键词：CRT / Pixel / Neon / Biohazard / Laboratory / Arcade。新版不追求更高像素数量，而追求：更强的轮廓、更清晰的层级、更完整的动画反馈。
**3.2 色板（基础色）**

| 培养皿深蓝黑 | #07121D |
| 深紫描边 | #241638 |
| UI 深紫 | #351D4A |
| 玩家青 | #38E8E0 |
| 高亮青白 | #C9FFFF |
| 感染橙 | #FF7138 |
| 危险黄橙 | #FFB347 |
| Boss 紫 | #A855F7 |
| Boss 高光 | #E6B4FF |
| 系统白 | #F3F7FA |
| 警报红 | #FF3B5C |
比例原则：深蓝黑 65% / 青 15% / 橙 12% / 紫 5% / 白 3%。
**3.3 精灵规范** —— 推荐逻辑分辨率：360 × 640。Canvas 根据设备 DPR 放大。
主角 PETRI-07：24×24 px 基础精灵，显示尺寸约 32–40 CSS px。组成：白色机器人主体、青色核心灯、深紫粗描边、2–3 帧浮动动画、2 帧受击闪烁、1 套死亡解体动画。
普通敌人：尺寸分三级：小 16×16、中 24×24、大 32×32。所有敌人必须满足：纯轮廓缩小到 50% 时仍能区分。
**3.4 "比老版更精致"的具体方法** —— 不是提升分辨率，而增加以下五层表现：
第一层：轮廓动画 —— 所有单位加入呼吸、抖动、挤压、变形，每个单位只需 2–4 帧。
第二层：攻击预备帧 —— 危险攻击必须存在 Normal → Anticipation → Attack → Recovery（正常 → 前摇 → 攻击 → 后摇），尤其是 Boss。
第三层：命中特效 —— 统一设计：白色中心闪光、对应阵营颜色外圈、3–5 个像素碎片、40–80ms hit-stop。
第四层：环境反馈 —— 背景培养皿加入液体流动、扫描线、气泡、污染脉冲、边缘玻璃反光，只使用程序动画与少量 tile。
第五层：局势状态 —— 培养皿会随着时间视觉恶化：0–2 分钟冷蓝稳定；2–5 分钟橙色污染增加；5–7 分钟紫色观察协议介入；Boss 战时背景接近黑色，仅保留安全区和弹幕高亮。这样同一张地图即可表现完整战局变化。

## 四、核心循环
**4.1 单局结构**（目标标准局：8 分钟）
| 时间 | 阶段 |
| 0:00–1:30 | 建立基础构筑 |
| 1:30–3:00 | 第一次路线分化 |
| 3:00 | 精英 A |
| 3:00–5:00 | 构筑成型 |
| 5:00 | 精英 B |
| 5:00–7:00 | 高压验证 |
| 7:00 | Boss |
| 7:00–8:30 | Boss 战 |
如果 Boss 超过 90 秒未死亡：进入"观察协议过载"，场地缓慢缩小，避免无限拖延。
**4.2 基础循环** —— 移动 → 自动战斗 → 冒险拾取资源 → 升级选择 → 调整构筑 → 面对更高压力。区别于传统 Survivors 的关键一步是：冒险拾取资源。

## 五、资源设计
玩家局内面对三种资源。EXP 数据：普通敌人掉落，负责升级。SAMPLE 样本：高威胁敌人、精英和危险区域产生，用于技能进化；样本不会被普通吸取范围自动远程收集，玩家必须靠近。HP：传统生命值，初始 100 HP。

## 六、"生命即弹药"的新处理
不把普通攻击绑定 HP。但设计一个可选机制：**紧急过载 Emergency Overdrive**。当玩家 HP ≤ 50% 时出现特殊升级"生命过载"。效果：长按摇杆之外的屏幕区域可开启；每秒消耗 3 HP，获得 +45% 攻速、+30% 移速、+25% 弹幕速度，最低只能烧至 1 HP。因此"生命值就是弹药"成为一个主动风险选择，而非每秒自动扣血的惩罚机制。玩家会真正产生"我现在要不要烧血抢掉这个精英？"的高频决策。MVP 中可以暂不实现，作为第二优先级机制。

## 七、技能系统
MVP：6 个基础技能。玩家最多装备 4 个，因此技能池天然存在机会成本。
**7.1 初始技能**
① 脉冲针 Pulse Needle —— 自动攻击最近敌人。初始：伤害 12、CD 0.55s、单体、射程 260。定位：稳定单体输出。
② 离心刃 Centrifuge Blade —— 围绕角色旋转，但刻意避免老版"回旋刃支配解"。初始：伤害 8、2 枚、半径 46、每目标命中 CD 0.45s。重大约束：装备离心刃时，样本拾取半径 -25%。定位：安全近战输出，但资源效率较低。
③ 培养电弧 Culture Arc —— 攻击最近敌人并弹射。伤害 10、弹射 2、每次弹射伤害 -20%。定位：清群。缺点：Boss 单体效率低。
④ 观察激光 Observation Beam —— 每 2.4 秒进行一次直线扫描。伤害 32、穿透无限、方向锁定 0.35 秒。缺点：玩家移动会改变瞄准条件。定位：走位规划型输出。
⑤ 冷却液泄漏 Coolant Leak —— 玩家移动时周期性留下减速区域。DPS 5、减速 25%、持续 2 秒。定位：空间控制。缺点：站桩时几乎无收益。
⑥ 实验无人机 Lab Drone —— 无人机自动绕场攻击。优点：安全、稳定。缺点：玩家自身拾取样本时无人机暂停攻击 0.4 秒。定位：安全输出 VS 资源效率。

## 八、技能升级结构
每个技能最多：5 级 + 进化。但不是简单伤害 +10%。建议结构：Lv2 基础强化；Lv3 第一次分支；Lv4 强化对应分支；Lv5 特性完成；Evolution 需要样本 + 条件才能进化。

## 九、示例：脉冲针分支
Lv3 出现：A：穿刺针 —— +1 穿透、伤害 -15%，路线：清怪。B：高压针 —— 单体伤害 +45%、攻速 -20%，路线：精英 / Boss。选择后锁定路线，不能同时获得。

## 十、合成 / 进化
进化不是传统技能 + 被动道具 = 固定神器。新版改为：技能 Lv5 + 指定数量 SAMPLE + 路线条件。例如脉冲针 Lv5：穿刺路线需要 20 SAMPLE，进化"针雨协议"：每第五次射击发射扇形针雨，但单发 Boss 伤害进一步 -20%。高压路线进化"处决针"：命中同一目标连续 4 次后，第 5 次造成 +150% 伤害，但切换目标后计数清空。因此两个版本分别对应群怪 / 单体。

## 十一、升级三选一生成规则
这是新版核心。三选一不能完全随机。采用：SLOT 1 当前构筑成长（已有技能升级）；SLOT 2 补缺口（系统检测当前弱点，如单体不足、清群不足、控场不足、资源不足，出现对应技能）；SLOT 3 改变打法（提供新技能、分支、风险型升级）。因此大多数升级选择应是"强化现在" vs "补足弱点" vs "改变路线"，而不是三个随机伤害按钮。

## 十二、通用升级
少量通用升级允许进入三选一，例如：磁吸线圈（样本拾取半径 +30%，但伤害 -8%）、高速协议（移动速度 +15%，但最大 HP -10%）、厚壁培养皿（最大 HP +20，但移动速度 -8%）、观察者标记（精英掉落 SAMPLE +40%，但精英 HP +20%）。这些升级直接制造机会成本。

## 十三、数值框架
目标不是精确平衡，而是给实现提供量纲。玩家：HP 100、移速 110 px/s、技能槽 4、拾取半径 42 px、无敌帧 0.45s。普通敌人：0 分钟约 15–25 HP；5 分钟 50–90 HP；Boss 约 5000–6500 HP。DPS 目标：1 分钟 20–30 DPS；3 分钟 45–65 DPS；5 分钟 80–110 DPS；最终构筑 130–180 DPS。不同构筑允许明显偏离，但综合通关能力应接近。

## 十四、支配解检查
每次新增技能必须过一张表，维度（评分 0–3）：单体 DPS、群体 DPS、防御能力、控场能力、资源效率、操作容错、Boss 能力。硬规则：任一技能不得有 4 个及以上维度达到 3 分，如果出现必须削掉至少一个维度。特别检查组合输出 + 安全 + 资源：一个技能如果这三个全部达到最高级，直接判定存在结构性支配风险。

## 十五、敌人设计（MVP 仅需 8 种）
1. 感染细胞 —— 最普通敌人，直接接近玩家，负责形成密度。
2. 冲刺菌 —— 停顿、橙色闪烁、0.6 秒后冲刺。作用：迫使玩家读前摇。
3. 分裂体 —— 死亡后分裂两个小单位。作用：惩罚纯慢速大伤害。
4. 喷射腺体 —— 远程敌人，每隔 2 秒向玩家当前位置射击。作用：逼迫持续移动。
5. 捕获体 —— 在地面生成橙色圆环，1 秒后减速。作用：限制安全区。
6. 采样寄生体 —— 会主动吞掉附近 SAMPLE，击杀后返还。作用：形成"要不要冒险追过去？"
7. 护膜体 —— 正面减伤 70%，背后正常。作用：奖励绕位。
8. 观察眼 —— 短暂锁定玩家，1 秒后射出细长激光。负责强化前摇识别。

## 十六、精英设计
精英 A：培养壁 —— 巨型慢速单位，持续向外释放小怪，自身伤害低。决定：先杀孵化器，还是清怪保安全区？
精英 B：采集者 —— 会吸收场上的 SAMPLE，每吸收一个攻击速度 +3%，击杀后全部返还并额外 +25%。因此玩家可以选择早杀稳定，或者故意养肥后冒险收割。这是新版很重要的风险收益节点。

## 十七、Boss：PETRI-06
定位：失败的前样本。视觉：深紫主体、类似 PETRI-07 的轮廓、部分机械结构已经感染、攻击前出现明显紫色器官充能。Boss 不大量召怪，Boss 战重点是弹幕空间阅读。

## 十八、PETRI-06 攻击模式（Boss 共三个阶段）
Phase 1：记录 —— 攻击 A：预测针刺：Boss 记录玩家当前位置，0.7 秒后攻击该位置，连续三次。正确策略是等锁定后移动；错误策略是一直高速绕圈（高速绕圈反而可能把三个危险区铺满整个安全空间）。攻击 B：扇形扫描：Boss 显示紫色扇形前摇，随后喷出弹幕，Boss 本体另一侧成为安全区。考验：看前摇 → 穿过 Boss 附近，而不是单纯逃远。
Phase 2：诱导（Boss HP ≤ 60%） —— 攻击 C：交叉实验：先释放竖向弹墙，1 秒后释放横向弹墙，两条弹墙之间必然存在移动窗口，要求玩家提前站位。攻击 D：伪安全区：场地出现三个青色圆，两秒后其中两个变橙，只有一个安全。判断规则：真正安全区会出现轻微白色扫描线。第一次玩家可能被骗，之后可以学习规则。
Phase 3：失控（Boss HP ≤ 25%） —— 培养皿边缘收缩，Boss 开始组合此前技能（预测针刺 + 扇形扫描），但攻击频率不显著增加，难度来自空间减少而非纯弹幕数量爆炸。

## 十九、Boss 数值设计原则
Boss 攻击造成 12–25 HP，不设计一次碰撞直接死亡。Boss 允许约 4–6 次失误。Boss 数值只负责让玩家不能无限拖，Boss 机制负责让玩家学习。

## 二十、Meta 成长
严格轻量，禁止出现 +500% 攻击力导致开局碾压。Meta 只用于降低摩擦 + 增加构筑自由。永久升级使用局外资源"实验记录 Research Data"，每局根据存活时间、击杀精英、Boss 阶段获得。升级包括：生存（最大 HP 最多 +10%）、机动（移动速度最多 +6%）、样本研究（SAMPLE 掉率最多 +10%）、初始协议（开局三选一从 3 个提升至 4 选 1，这是最有价值的 Meta，因为增加的是选择权不是纯数值）。

## 二十一、局外解锁
主要进度来自技能解锁。例如：击败 PETRI-06 解锁观察激光；一局收集 50 SAMPLE 解锁实验无人机；使用离心刃通关解锁另一条进化路线。让玩家目标明确。

## 二十二、竖屏 UI
逻辑设计基准 360 × 640。顶部 12%：第一行 HP BAR；第二行左 03:42、中央 LV 8、右 SAMPLE 14。中央约 70% 完全留给战场，禁止任务框、大头像、技能描述长期占据战斗空间。下方 18%：左下透明虚拟摇杆，推荐视觉半径 44px、实际响应半径 70px，且支持 Floating Joystick（手指落在哪里，摇杆中心就在哪里），比固定左下角更适合手机浏览器。

## 二十三、技能 HUD
右侧排列四个技能小图标，只展示图标、Lv、进化状态。自动技能不显示 CD 数字，减少信息噪音。

## 二十四、升级界面
升级时完全暂停游戏。屏幕中央纵向出现三张卡片，每张只显示图标、名称、一句效果、一句代价。例如高压针：单体伤害 +45%、攻击速度 -20%。必须让玩家在 2–3 秒内读懂选择。

## 二十五、信息层级
游戏过程中玩家视觉优先级：第一层 玩家 / 敌人 / 弹幕 / 危险范围；第二层 掉落物 / 安全区；第三层 HP；第四层 经验 / SAMPLE；第五层 技能状态。除 HP 之外，HUD 不应比战场单位更亮。

## 二十六、移动端交互原则
只要求一个手指。禁止基础玩法依赖：双指、按技能按钮、滑动组合技、长按 UI、精准点击。唯一允许增加的第二交互是未来版本的生命过载，并且必须做成：长按屏幕任意非摇杆区域。

## 二十七、音效
声音方向：电子实验设备 + 街机合成器 + 有机污染。玩家攻击：短促 tik / zap / pip，高频攻击音量很低，避免疲劳。击杀：普通为轻微爆裂；精英为低频 THUMP + 样本玻璃破裂感。拾取 SAMPLE：清晰高音 ting，连续拾取会逐渐升高音阶，形成收集爽感。玩家受伤：不使用尖锐报警，采用低频冲击 + 机器人故障噪声。

## 二十八、音乐
BPM 110–135。类型：Synthwave、Chiptune、Industrial electronic，但保持克制。音乐采用三个 Stem：基础层（鼓 + Bass）、污染层（2 分钟后加入失真 synth）、Boss 层（加入紫色主题 lead）。无需准备三首曲，只需一首循环 BGM + 三层音轨，资源效率更高。

## 二十九、MVP 美术资产预算（按 1–2 人周）
角色：PETRI-07 约 12 帧。敌人：8 种 × 2–4 帧，约 24 帧。Boss：约 12–16 帧。技能：6 个图标、6 套弹幕 / 特效。UI：HP 条、EXP 条、SAMPLE 图标、6 技能图标、升级卡、主菜单、结算页。环境：无需完整 tile map，只需要培养皿底图、3–4 种污染纹理、气泡、扫描线、边缘结构。总工作量明显低于传统关卡制作。

## 三十、前端实现建议
技术结构尽量简单：Game ├─ Player ├─ EnemyManager ├─ ProjectileManager ├─ SkillManager ├─ DropManager ├─ WaveDirector ├─ BossController └─ UI。所有数值写入 data.js，技能配置 skills = { pulseNeedle: {...}, centrifugeBlade: {...} }，敌人同理。不要早期做 ECS。MVP 使用对象池 Object Pooling（对象复用）处理敌人、弹幕、掉落物、粒子即可。

## 三十一、性能预算
目标：中端手机浏览器稳定 60 FPS。同屏上限建议：普通敌人 80–100、玩家弹幕 80、敌方弹幕 120、粒子 80。超过时优先复用 / 合并视觉表现，不要依赖数百实体制造爽感。新版爽感主要来自死亡连锁反馈 + 音效 + hit-stop + 屏幕震动。

## 三十二、首版不做
为了避免再次陷入内容堆积，首版明确不做：多角色、多地图、装备品质系统、随机词缀、商店、每日任务、宠物、成就系统、排行榜、云存档、多 Boss、大型技能树。只有一个问题值得验证：这套构筑和移动系统，连续玩三局时，玩家是否愿意尝试不同选择？如果答案不是明确的"是"，任何新内容都不应该制作。

## 三十三、MVP 验证指标
建议进行 10–20 人小样本试玩，核心观察四项。指标 1：技能选择集中度 —— 如果超过 70% 玩家长期优先选择同一技能，检查支配解。指标 2：构筑多样性 —— 通关构筑中任何单一组合占比不应超过 40%。指标 3：三选一犹豫时间 —— 理想 2–6 秒；如果 <1 秒说明存在明显最优解；如果 10 秒说明信息表达过于复杂。指标 4：Boss 死亡认知 —— 死亡后问"你觉得刚才为什么死？"理想答案："我没躲开那个扫描。""我站错安全区。"而不是"伤害不够。"

## 三十四、差异化一句话（对玩家）
《培养皿：弹幕余生》是一款"自动攻击，但不能自动思考"的竖屏割草游戏——你不是在堆最强武器，而是在培养皿里不断决定：输出、安全和资源，这一刻你愿意牺牲哪一个。

## 三十五、为什么不直接玩《弹壳特攻队》
《弹壳特攻队》的爽点主要来自：成长 → 火力膨胀 → 大面积清屏。《培养皿》的核心体验应是：危险空间 → 构筑取舍 → 读招 → 找安全区。所以它不应该试图成为一个内容更少的《弹壳特攻队》，它应该成为：更短、更紧、更强调走位与构筑判断的"弹幕型 Survivors"。

## 三十六、推荐开发顺序
Prototype 0：移动是否舒服 —— 只实现 PETRI-07 + 摇杆 + 20 个追踪敌人，目标：手机单手移动没有摩擦。
Prototype 1：战斗是否爽 —— 增加脉冲针、离心刃、电弧、命中特效、死亡反馈，目标：移动 + 自动攻击本身有爽感。
Prototype 2：决策是否成立 —— 增加 SAMPLE、三选一、两个技能分支、4 技能槽，只测试玩家是否会改变选择，这是项目最重要的 Gate。
Prototype 3：机制 Boss —— 实现 PETRI-06，无需 Meta。如果一个几乎裸数值的玩家理解机制后能稳定提升 Boss 表现，则 Boss 设计成立。
Prototype 4：完整 8 分钟 —— 最后才加入完整刷怪节奏、8 敌人、精英、Meta、美术包装、音乐，itch.io 发布。

## 最终设计判断
这个重制版最需要避免的不是"像不像 Vampire Survivors"，而是"玩家是否再次在几十秒后就知道以后该永远选什么"。因此新版所有系统都应该围绕一个判断标准：一个选择如果没有让另一个有价值的东西变得更难获得，它通常就不是一个真正的构筑选择。《培养皿：弹幕余生》的核心不是"更多技能"，而是：有限的四个技能槽、不断恶化的战场，以及永远不能同时拿到的三样东西——火力、安全和资源。

这版里我认为最值得直接拿去做原型的是 "4 技能槽 + SAMPLE 进化资源 + Lv3 不可逆分支 + 输出/安全/资源三维支配解检查"。它比重新把"生命=弹药"硬塞回主循环更有机会真正解决老版的决策空间问题。
