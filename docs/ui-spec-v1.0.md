## 1. 设计原则与坐标规范

### 1.1 视觉原则
- 深紫色作为游戏世界与 UI 的统一背景
- 霓虹绿 = 构筑强化与正向成长；霓虹橙 = 补弱点/危险/生存干预；霓虹紫 = 变异/路线改变/进化
- 白色主信息，淡紫说明信息
- 像素元素用于图标/边框角饰/粒子/环境，不牺牲中文字形清晰度
- 战斗期间 HUD 必须克制，重要决策通过暂停战斗后的模态面板展示

### 1.2 坐标系统
- Canvas 左上角原点，X 右增（0–1080），Y 下增（0–1920）
- 元素矩形 (x, y, width, height)，默认安全边距 24px

### 1.3 适配约定
```js
const BASE_W = 1080, BASE_H = 1920;
const scale = Math.min(W / BASE_W, H / BASE_H);
const offsetX = (W - BASE_W * scale) / 2;
const offsetY = (H - BASE_H * scale) / 2;
```
- UI 坐标先按 scale 缩放再叠加偏移；不足 9:16 区域背景延展填充；不允许拉伸变形
- 考虑 DPR；刘海屏/手势区用 safe-area-inset；HUD 以顶部安全区为锚点

## 10. Canvas 绘制规范

### 绘制顺序
1. 清画布 → 2. 背景底色 → 3. 地面/装饰/像素网格 → 4. 敌人/玩家/世界物体 → 5. 子弹/命中特效/粒子 → 6. HUD 面板背景边框 → 7. 技能图标/进度条 → 8. HUD 文字 → 9. 虚拟摇杆 → 10. 战斗提示
模态追加：11. 全屏遮罩 → 12. 模态主面板 → 13. 卡片底色 → 14. 卡片边框发光 → 15. 图标 → 16. 标签/标题/说明 → 17. 交互强调
升级/进化/暂停/死亡互不重叠

### 发光实现（两次描边）
```js
// 第一次：发光层
ctx.save();
ctx.strokeStyle = "#39FF6A"; ctx.lineWidth = 3;
ctx.shadowColor = "rgba(57,255,106,0.75)"; ctx.shadowBlur = 20;
ctx.shadowOffsetX = 0; ctx.shadowOffsetY = 0;
drawCardPath(ctx); ctx.stroke(); ctx.restore();
// 第二次：清晰描边层
ctx.save();
ctx.strokeStyle = "#39FF6A"; ctx.lineWidth = 3; ctx.shadowBlur = 0;
drawCardPath(ctx); ctx.stroke(); ctx.restore();
```

### shadowBlur 性能
- 不对所有粒子开大范围发光；UI 发光优先静态缓存（离屏 Canvas，只在尺寸/状态/主题变化时重生成）
- 文本外发光尽量少用；小粒子用明亮色块代替 shadowBlur；高频战斗特效与低频 UI 特效分开处理

### 像素美术
`ctx.imageSmoothingEnabled = false`；像素精灵整数倍放大、对齐整数像素；图标统一笔画粗细；背景装饰低对比度

### 中文渲染
```js
ctx.textAlign = "center"; ctx.textBaseline = "middle";
ctx.font = "700 48px 'Noto Sans SC', sans-serif";
```
- `document.fonts.ready` 等字体加载完成；用 measureText 换行，不按字符数估算
- 技能名最多 2 行，描述最多 3 行；超长精简文案；中文标点不单独行首；数值变化用颜色/数字/符号表达；不用大范围文字发光

### 文本溢出规则
HUD 数值/技能等级/样本计数单行；卡片类别单行不裁剪；技能名优先单行最多 2 行；等级变化单行；效果描述最多 3 行

## 11. 输入与状态管理
```js
const UIState = { RUNNING: "running", LEVEL_UP: "level_up", EVOLUTION: "evolution", PAUSED: "paused", DEAD: "dead" };
```
| 状态 | 战斗更新 | 摇杆 | HUD | 模态 |
|---|---|---|---|---|
| RUNNING | 是 | 可用 | 正常 | 无 |
| LEVEL_UP | 否 | 禁用 | 暗化 | 三选一 |
| EVOLUTION | 否 | 禁用 | 暗化 | 二选一 |
| PAUSED | 否 | 禁用 | 暗化 | 暂停 |
| DEAD | 否 | 禁用 | 暗化 | 死亡 |

模态优先级：DEAD > EVOLUTION > LEVEL_UP > PAUSED > RUNNING；任何时刻最多一个主模态
触控坐标换算回设计坐标：`logicalX = (clientX - offsetX) / scale`
卡片整卡可点；技能槽默认不可点；模态期间屏蔽底层触控；同一触摸不双命中

## 12. 响应式与性能
- 目标 60 FPS；UI 静态资源预渲染缓存；粒子设预算；不每帧重建字体/渐变对象
- 高 DPR 监控 Canvas 像素数；必要时降渲染分辨率不降逻辑坐标精度；模态打开暂停世界模拟
- 三选一在 9:16 下固定三列；极窄屏可用紧凑排版，不只靠压字号
